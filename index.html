1. Authorized nodeCoach must initialize a training node with ≥10 minutes active GPS dwell.
2. 500m fenceCoach device must remain inside the registered node radius to stay geographically valid.
3. 50m handshakeCoach and athlete devices must ping within 50m for proof of presence.
4. Hardware + UTCIMEI/MAC anchor and server-side UTC timestamps block remote logging and backdating.
Verification gate logic
node_active = dwell_minutes >= 10
geo_valid = haversine(coach_lat, coach_lng, node_lat, node_lng) <= 500m
presence_valid = haversine(coach_lat, coach_lng, athlete_lat, athlete_lng) <= 50m
device_valid = device_anchor_ok == true
time_valid = utc_source == "SERVER"

VERIFIED = node_active AND geo_valid AND presence_valid AND device_valid AND time_valid
FLAGGED = geo_valid AND NOT presence_valid
REJECTED = NOT geo_valid
integrity_score = verified_sessions / total_sessions * 100
gold_seal = integrity_score >= 90 over continuous 90-day window
